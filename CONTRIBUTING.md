# Contribuindo

1. Crie um fork e uma branch descritiva.
2. Instale as dependencias: `pip install -r requirements.txt`
3. Rode `ruff check src tests` e `pytest`.
4. Abra um pull request com descricao do problema e da solucao.

Nunca envie alvos reais de terceiros em `config/config.yaml`, nem resultados de varreduras contra redes que voce nao administra.
